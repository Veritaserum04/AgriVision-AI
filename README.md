# 🌱 AgriVision AI

Plant Disease Detection using Deep Learning.

## Features

- Detects 15 plant diseases
- Built using PyTorch
- Transfer Learning using ResNet18
- 20,638 PlantVillage Images
- Interactive Gradio Interface

## Accuracy

Validation Accuracy: **93.60%**

## Tech Stack

- Python
- PyTorch
- Torchvision
- Gradio
- NumPy
- Scikit-Learn

## Dataset

PlantVillage Dataset

## Run

```bash
pip install -r requirements.txt

python app.py
```
